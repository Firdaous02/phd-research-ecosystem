# phd-research-ecosystem

## Project Description
This repository provides an organized environment for managing
bibliographic references, research documentation, data management
resources, and supporting materials related to my PhD research.

## Repository Structure
- `bibliography/`: Scientific references in BibTeX format.
- `research_data/`: Documentation about research data.
- `data_management/`: Data Management Plan.
- `documents/`: Research notes and documentation.
- `figures/`: Research-related figures.
- `reports/`: Project reports.
